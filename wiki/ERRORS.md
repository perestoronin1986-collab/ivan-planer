# Уроки и допущенные ошибки

> Цель: фиксировать факапы и грабли, чтобы не повторять. Каждый блок — симптом, причина, фикс, как избежать.

---

## 2026-05-16 — Прямой TCP к Supabase Postgres заблокирован

**Симптом:** Drizzle ORM через `postgres` (`5432`/`6543`) не подключается, таймауты.
**Причина:** Сеть/провайдер блокирует прямой TCP к Supabase.
**Фикс:** Переписать слой данных на PostgREST через `@supabase/supabase-js`. Drizzle runtime удалён, `schema.ts` оставлен только для миграций (`drizzle-kit`).
**Урок:** Перед выбором драйвера БД — проверить сетевую доступность TCP-портов из dev-окружения. Для Supabase под Win/Россия — сразу PostgREST.

## 2026-05-18 — `revalidatePath` отсутствовал у `toggleTask`/`deleteTask`

**Симптом:** После клика чекбокса задача не обновлялась в UI до ручного refresh.
**Причина:** Server action менял БД, но Next.js кэш страницы не инвалидировал.
**Фикс:** `revalidatePath("/today")` в каждом action, который меняет видимые данные.
**Урок:** Любой server action, мутирующий данные → добавлять `revalidatePath` для всех затронутых маршрутов. Чек-лист при создании нового action.

## 2026-05-18 — `datetime-local` input → не ISO

**Симптом:** `due_at` в БД сохранялся со сдвигом часового пояса.
**Причина:** HTML `<input type="datetime-local">` возвращает локальную строку без TZ (`2026-05-18T14:00`), а не ISO.
**Фикс:** Хелпер `toIso()` в `spheres/actions.ts` — добавляет TZ-смещение или конвертирует в UTC.
**Урок:** Никогда не отдавать значение `datetime-local` напрямую в БД. Всегда через конвертер.

## 2026-05-19 — Сравнение дат строкой ломалось на Supabase

**Симптом:** Условие `task.due_at < today` давало неверный результат для свежих задач.
**Причина:** Supabase возвращает `+00:00`, JS Date.toISOString → `.000Z`. Лексикографическое сравнение строк не работает.
**Фикс:** Сравнивать только через `new Date(x).getTime()`.
**Урок:** Даты — только через `.getTime()`. Никаких `>` `<` на строках ISO.

## 2026-05-19 — Reschedule просрочки сдвигал `due_at` на `now+24h`

**Симптом:** Задача с просрочкой улетала на завтра.
**Причина:** `processOverdueTasks` ставил `dueAt = new Date(Date.now() + 24*3600*1000)`.
**Фикс:** `reschedule` → ставит на **сегодня** (полночь), потом `keeps task overdue, never moves due_at` (22cb0b7) — оставляет задачу в overdue-секции, только инкрементирует `carry_count`.
**Урок:** Правила для overdue: не "перенести на потом", а "оставить видимой сейчас + посчитать перенос".

## 2026-05-19 — `createRecurringTask` мог создать > 500 вхождений

**Симптом:** Зависание сервера на rrule с большим диапазоном.
**Причина:** Нет лимита на количество occurrences.
**Фикс:** Кап на 500, валидация через Zod, rollback шаблона при ошибке вставки вхождений (логировать ошибку rollback).
**Урок:** Любая операция, генерирующая массив записей из пользовательского ввода — лимит сверху обязательно.

## 2026-05-21 — `Dexie.where("processed_at").equals(null)` падал

**Симптом:** Inbox-список не загружался офлайн.
**Причина:** IndexedDB не индексирует `null` как ключ.
**Фикс:** `toArray().filter(x => x.processed_at == null)` в JS.
**Урок:** Dexie/IndexedDB — фильтр по `null` всегда через `.filter()`, не через индекс.

## 2026-05-21 — PWA manifest и `/offline` требовали авторизацию

**Симптом:** Установка PWA на устройстве падала с 401 на manifest.
**Причина:** Middleware Supabase редиректил на `/login` все маршруты включая `/manifest.webmanifest`, `/offline`, `/icon*`.
**Фикс:** Расширить `PUBLIC_PATHS` в middleware.
**Урок:** При добавлении PWA-эндпоинтов — сразу прописывать в публичный whitelist.

## 2026-05-21 — Outbox poison entry блокировал sync

**Симптом:** Один битый item в outbox → весь sync встаёт.
**Причина:** FIFO останавливался на ошибке, attempts++ без верхнего лимита.
**Фикс:** Dead-letter outbox: после N попыток entry помечается как failed, sync продолжает следующий. Guard против poison entries.
**Урок:** Очереди с FIFO семантикой — всегда dead-letter после M попыток, иначе одно битое сообщение парализует пайплайн.

## 2026-05-22 — Service Worker не обновлял shell при выкатке

**Симптом:** Старые клиенты после деплоя видели stale UI.
**Причина:** Версия кэша SW не менялась → install-skip.
**Фикс:** Bump `VERSION` константы в `public/sw.js` при каждом изменении shell.
**Урок:** Любая правка `sw.js` или precache-списка → инкремент `VERSION`. Иначе кэш на устройствах залипает.

## 2026-05-22 — Middleware падал при сетевой ошибке Supabase

**Симптом:** При обрыве сети средне-сессии пользователь выкидывало на `/login`.
**Причина:** `getSession()` в middleware кидал → fail-closed на `/login`.
**Фикс:** try/catch — на сетевую ошибку оставлять текущую сессию из cookie (fail-open для оффлайн).
**Урок:** Auth-middleware в PWA — fail-open при сетевых ошибках, fail-closed только при доказанной невалидности токена.

## 2026-05-26 — Дизайн-разнобой: neutral vs brand

**Симптом:** Главная — фиолетовая, остальные экраны — серые/плоские.
**Причина:** Tailwind v4 не настроен `@theme inline`, brand-классы не работали, разработчики падали на neutral.
**Фикс:** Токены в `globals.css` + `@theme inline` → классы `bg-brand-50`, `text-brand-600` работают. UI-компоненты `PageShell`, `Section`, `Tile`, `ActionButton`, `Chip`, `EmptyState`. Гайд `wiki/DESIGN.md`.
**Урок:** Дизайн-систему фиксировать ДО разработки фич. Любая новая страница → `PageShell` + `Section`, никогда `<div className="bg-white border">`.

## 2026-06-11 — Пароль Postgres в публичном репо

**Симптом:** `scripts/test-db.ts` содержал захардкоженный пароль БД, файл в git с initial commit, репозиторий публичный.
**Причина:** Диагностический скрипт времён отладки TCP-подключения закоммитили вместе с секретом.
**Фикс:** Файл удалён. **Пароль НУЖНО сменить** в Supabase Dashboard → Settings → Database → Reset password (удаление из репо не чистит историю коммитов).
**Урок:** Секреты только в `.env.local`. Любой одноразовый скрипт с кредами — в `.gitignore` или сразу удалять.

## 2026-06-11 — Magic link в dev уводит на прод

**Симптом:** Логин с localhost: письмо приходит, но `redirect_to` в ссылке — прод (`ivan-planer.vercel.app`), локальная сессия не создаётся.
**Причина:** `http://localhost:3000/**` нет в Supabase Auth → URL Configuration → Redirect URLs. Supabase молча заменяет недопустимый redirect на Site URL.
**Фикс:** Добавить `http://localhost:3000/**` в Redirect URLs allowlist (Dashboard, кодом не чинится).
**Урок:** Недопустимый `emailRedirectTo` Supabase не отклоняет с ошибкой, а тихо подменяет — проверять allowlist при настройке новых окружений.

## Технический долг (не ошибки, но грабли впереди)

- **Middleware deprecated в Next.js 16** — рекомендуется `proxy` файл. Пока работает, но при апгрейде убрать.
- **Supabase JWT refresh оффлайн** — токен в localStorage живёт ~1ч, без сети refresh упадёт. Продлить срок сессии в Supabase project settings, если будут жалобы.
- **`order` колонка int** — при ручном drag-and-drop потребуется fractional indexing (`order: 1.5`), сейчас целочисленный.
